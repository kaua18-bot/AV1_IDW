# 📝 Lista de Tarefas (To-Do List)

Um projeto simples de lista de tarefas desenvolvido com **HTML, CSS e JavaScript puro**, permitindo adicionar, editar e excluir tarefas de forma dinâmica.

---

## 🚀 Funcionalidades

- ✅ Adicionar novas tarefas
- ✏️ Editar tarefas existentes
- ❌ Excluir tarefas
- ⚠️ Validação de campo vazio
- 📊 Contador de tarefas
- 🎨 Interface moderna com efeito glassmorphism

---

## 🖥️ Demonstração

Interface com:
- Fundo estilizado
- Card central com blur (glass effect)
- Lista dinâmica de tarefas

🧠 Lógica principal:
As tarefas são armazenadas em um array:
const tarefas = [];
Ao adicionar:
Valida se o campo está vazio
Insere no array
Atualiza a tela
Ao editar:
Substitui o valor no array
Re-renderiza a lista
Ao excluir:
Remove a tarefa com splice()
Atualiza a interface
